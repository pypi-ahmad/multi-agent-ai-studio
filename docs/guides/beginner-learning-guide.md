# Beginner Learning Guide

## Learning Path

1. Start API and web UI locally.
2. Register account and create first workflow graph.
3. Run chat orchestration and inspect model routing snapshot.
4. Add memory records and query them.
5. Ingest documents and test retrieval.
6. Execute tool calls with confirmation headers.
7. Run evaluation entries and cost estimation.
8. Inspect traces and system metrics.

## Why This Matters

This sequence builds practical understanding of modern agentic AI stack components: orchestration, retrieval, observability, and safety controls.
